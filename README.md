# مشغل M3U (Android + Android TV)

تطبيق Kotlin / Jetpack Compose يعمل على الموبايل وشاشات Android TV بواجهة عربية (RTL).
التطبيق مشغّل فقط، لا يتضمن أي قنوات أو محتوى.

## التشغيل
1. افتح المجلد في **Android Studio** (Koala أو أحدث) ثم انتظر مزامنة Gradle.
2. شغّله على جهاز أو محاكي (الموبايل أو Android TV).
3. لإنشاء ملف APK: `Build > Build APK(s)`، ثم ثبّته على التلفاز بـ `adb install app-debug.apk`.

> ملف `gradle-wrapper.jar` غير مرفق. Android Studio ينزّل Gradle 8.7 تلقائياً من `gradle-wrapper.properties`.
> للبناء من الطرفية: نفّذ `gradle wrapper --gradle-version 8.7` مرة واحدة.

## الميزات
- **أول تشغيل:** شاشة إضافة قائمة (رابط M3U + اسم اختياري).
- **التصنيف التلقائي:** بث حي / أفلام / مسلسلات (من مسارات `/movie/` و`/series/` وامتداد الرابط واسم الباقة).
  المسلسلات تُجمَّع حسب الاسم والموسم والحلقة (`S01E05`، `1x05`، «الموسم 1 الحلقة 5»).
- **الرئيسية:** متابعة المشاهدة (أفلام/حلقات لم تكتمل، وبعد انتهاء حلقة تظهر التالية)، المباريات والقنوات المثبتة، وصفوف قوائم المفضلة.
- **البث الحي:** باقات + بحث. ضغطة مطوّلة (أو ⋮) على القناة: مفضلة، إضافة لقائمة، **تثبيت في الرئيسية** باسم المباراة. ضغطة مطوّلة على الباقة: إضافتها كاملة إلى قائمة مفضلة.
- **المفضلة:** عدة قوائم، إنشاء/إعادة تسمية/حذف، **نقل** العناصر بين القوائم، وترتيبها لأعلى/لأسفل. يمكن إضافة المسلسلات (بنجمة داخل صفحة المسلسل أو بالضغط المطوّل).
- **المشغّل:** ExoPlayer (HLS/TS/MP4/MKV)، استئناف من آخر موضع، حلقة تالية تلقائياً، إعادة اتصال للبث الحي.
- **الريموت:** كل العناصر قابلة للتركيز مع إطار تمييز؛ زر OK للتشغيل، والضغط المطوّل لقائمة الخيارات.
